## 🇪🇸 Español

**El Gran Misteri** es un juego de detectives en el que interrogas sospechosos, encuentras pistas, exploras escenarios y resuelves el caso. Se juega directamente en el navegador, sin instalar nada.

### Cómo jugar
1. Abre el enlace: **https://TU_USUARIO.github.io/el-gran-misteri/**
2. Elige el idioma (Español, English o Valencià).
3. Interroga a los sospechosos, recoge pistas y acusa al culpable.

El progreso se guarda automáticamente en tu navegador.

### Ejecutar en local
```bash
git clone https://github.com/TU_USUARIO/el-gran-misteri.git
cd el-gran-misteri
# Abre index.html en tu navegador, o sirve la carpeta:
python3 -m http.server 8080
```
Luego visita `http://localhost:8080`.

## 🚀 Publicar con GitHub Pages

1. Sube este repositorio a GitHub (rama `main`).
2. Ve a **Settings → Pages**.
3. En *Source* selecciona **Deploy from a branch** → `main` → `/ (root)` → **Save**.
4. En un minuto el juego estará disponible en `https://TU_USUARIO.github.io/el-gran-misteri/`.

> Sustituye `TU_USUARIO` por tu nombre de usuario de GitHub en este README.
